# Musix 设计文档

## 1. 项目概述

### 1.1 项目目标
实现一个支持多平台、用于获取音乐和视频信息的通用后端服务程序，提供统一的API接口访问不同媒体平台的资源。

### 1.2 核心特性
- **多平台支持**：支持网易云音乐、Bilibili等主流媒体平台
- **统一接口**：通过抽象基类提供一致的服务调用方式
- **异步架构**：基于 async/await 的异步设计，提高并发性能
- **认证管理**：支持平台账号登录与会话管理
- **扩展性强**：易于添加新的媒体平台支持

### 1.3 技术栈
- **语言**：Python 3.9+
- **核心依赖**：
  - `pyncm`：网易云音乐 API
  - `bilibili-api-python`：Bilibili API
  - `python-dotenv`：环境变量管理
  - `aiohttp`：异步 HTTP 客户端

### 2.2 核心模块

#### 2.2.1 MediaService (媒体服务基类)
位置：`media_service.py`

**职责**：
- 定义所有媒体服务的通用接口
- 提供默认实现的可选功能方法

**核心方法**：
- `search(keywords, page, **kwargs)` - 搜索媒体资源
- `get_media_info(media_id, **kwargs)` - 获取媒体详细信息
- `get_hot_list(limit, **kwargs)` - 获取热门排行（可选）
- `get_recommendations(limit, **kwargs)` - 获取推荐内容（可选）

**返回数据结构**：
```python
# 搜索结果
{
    "items": [],           # 媒体项列表
    "total_count": 0,      # 总数量
    "current_page": 1      # 当前页码
}

# 媒体详情（各平台差异）
{
    "title": str,          # 标题
    "desc": str,           # 描述
    "url": str,            # 播放链接
    ...                    # 其他平台特定字段
}
```

#### 2.2.2 AuthenticatedMediaService (认证服务基类)
继承自 `MediaService`

**职责**：
- 处理需要用户登录的媒体服务
- 管理登录状态和用户信息

**核心属性**：
- `is_logged_in: bool` - 登录状态
- `user_info: dict` - 用户信息

**核心方法**：
- `check_login_status()` - 检查登录状态
- `login()` - 登录方法（子类实现）
- `logout()` - 登出方法（子类实现）

#### 2.2.3 NeteaseService (网易云音乐服务)
位置：`services/netease_service.py`

**功能**：
- 音乐搜索
- 歌曲信息获取
- 播放链接获取
- Cookie 登录
- 手机号登录
- 获取用户歌单
- 获取热门排行榜

**认证方式**：
- Cookie登录（MUSIC_U）
- 手机号密码登录
- 手机号验证码登录

**环境变量**：
```
NETEASE_MUSIC_U=your_music_u_cookie
NETEASE_PHONE=your_phone_number
NETEASE_PASSWORD=your_password
```

#### 2.2.4 BilibiliService (B站视频服务)
位置：`services/bilibili_service.py`

**功能**：
- 视频搜索
- 视频信息获取
- 视频流、音频流链接获取
- Credential 认证

**认证方式**：
- SESSDATA、BILI_JCT、BUVID3 凭证

**环境变量**：
```
SESSDATA=your_sessdata
BILI_JCT=your_bili_jct
BUVID3=your_buvid3
```

## 4. 接口设计

### 4.1 通用接口规范

所有服务类都应实现以下接口：

```python
class MediaService(ABC):
    async def search(keywords: str, page: int = 1, **kwargs) -> dict
    async def get_media_info(media_id: Any, **kwargs) -> dict
    async def get_hot_list(limit: int = 50, **kwargs) -> dict
    async def get_recommendations(limit: int = 20, **kwargs) -> dict
```

### 4.2 认证接口

```python
class AuthenticatedMediaService(MediaService):
    async def check_login_status() -> dict
    async def login(**kwargs) -> dict
    async def logout() -> dict
    async def get_user_playlists(**kwargs) -> dict
```

### 4.3 平台特定接口

#### NeteaseService 扩展接口
```python
async def login_by_cookie(cookie: Optional[str] = None) -> dict
async def login_by_phone(phone: str, password: str) -> dict
async def login_by_captcha(phone: str, captcha: str) -> dict
async def send_captcha(phone: str) -> dict
async def get_song_url(song_id: int, bitrate: int = 320000) -> dict
async def get_lyrics(song_id: int) -> dict
async def get_daily_recommendations() -> dict
async def get_top_list(list_id: int) -> dict
```

#### BilibiliService 扩展接口
```python
async def get_video_pages(bvid: str) -> dict
async def get_video_download_url(bvid: str, page: int = 0) -> dict
```

## 5. 使用示例

### 5.1 网易云音乐使用示例

```python
from services.netease_service import NeteaseService

async def main():
    # 初始化服务（自动使用环境变量中的cookie登录）
    netease = NeteaseService()
    
    # 检查登录状态
    status = await netease.check_login_status()
    print(f"登录状态: {status['is_logged_in']}")
    
    # 搜索歌曲
    results = await netease.search("周杰伦", page=1)
    print(f"找到 {results['total_count']} 首歌曲")
    
    # 获取歌曲详情
    if results['items']:
        song_id = results['items'][0]['id']
        info = await netease.get_media_info(song_id)
        print(f"歌曲: {info['song_name']}")
        print(f"播放链接: {info['play_url']}")
    
    # 获取用户歌单
    playlists = await netease.get_user_playlists()
```

### 5.2 Bilibili 使用示例

```python
from services.bilibili_service import BilibiliService

async def main():
    # 初始化服务
    bilibili = BilibiliService()
    
    # 搜索视频
    results = await bilibili.search("技术分享", page=1)
    print(f"找到 {len(results['items'])} 个视频")
    
    # 获取视频详情
    if results['items']:
        bvid = results['items'][0]['bvid']
        info = await bilibili.get_media_info(bvid)
        print(f"视频: {info['title']}")
        print(f"UP主: {info['owner']['name']}")
        print(f"播放量: {info['stat']['view']}")
        print(f"视频流: {info['video_url']}")
        print(f"音频流: {info['audio_url']}")
```

## 6. 配置管理

### 6.1 环境变量配置

项目使用 `.env` 文件管理配置信息：

```bash
# 网易云音乐配置
NETEASE_MUSIC_U=your_music_u_cookie_here

# Bilibili配置
SESSDATA=your_sessdata_here
BILI_JCT=your_bili_jct_here
BUVID3=your_buvid3_here
```

### 6.2 配置获取流程

1. 服务初始化时自动加载 `.env` 文件
2. 通过 `os.getenv()` 读取配置项
3. 如果配置项存在且 `auto_login=True`，自动尝试登录
4. 登录失败不影响服务正常使用，仅影响需要认证的功能

## 10. 扩展开发指南

### 10.1 添加新平台支持

要添加新的媒体平台支持，需要：

1. **创建服务类**：在 `services/` 目录下创建新的服务文件
2. **继承基类**：根据需求继承 `MediaService` 或 `AuthenticatedMediaService`
3. **实现必需方法**：
   - `search()` - 搜索功能
   - `get_media_info()` - 获取详情
4. **实现可选方法**：
   - `get_hot_list()` - 热门排行
   - `get_recommendations()` - 推荐内容
5. **添加认证逻辑**（如需要）：
   - `check_login_status()`
   - `login()`
   - `logout()`

### 10.2 服务类模板

```python
from media_service import AuthenticatedMediaService

class NewPlatformService(AuthenticatedMediaService):
    """新平台服务类"""
    
    def __init__(self, auto_login: bool = True):
        super().__init__(auto_login)
        # 初始化平台特定的客户端
    
    async def search(self, keywords: str, page: int = 1, **kwargs) -> dict:
        """搜索实现"""
        # 调用平台API
        # 格式化返回数据
        return {
            "items": [],
            "total_count": 0,
            "current_page": page
        }
    
    async def get_media_info(self, media_id, **kwargs) -> dict:
        """获取详情实现"""
        # 调用平台API
        # 返回详细信息
        return {}
    
    async def check_login_status(self) -> dict:
        """检查登录状态"""
        return {
            "is_logged_in": self.is_logged_in,
            "user_info": self.user_info
        }
```
